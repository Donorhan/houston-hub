# GitHub

Browse and search repositories, code, commits and branches; read files, diffs and
CI results; follow issues, pull requests, reviews, releases, workflow runs and
gists across your personal account and organizations; and catch up on recent
activity and starred repositories.

Each connection sets one access level per area:

| Access | Read | Write |
| --- | --- | --- |
| **Code and releases** | Files, branches, commits, compare, archives, releases and their assets, code and commit search | Commit and delete files, git blobs, trees, commits and refs, merge and rename branches, sync forks, comment on commits, manage releases |
| **Issues and pull requests** | Issues, pull requests, comments, reviews, labels, milestones, assignees and collaborators, issue search | Open, edit, close, comment, react, label, assign and review |
| **Actions, checks and statuses** | Workflows, runs, jobs, logs, artifacts, check runs and suites, commit statuses | Dispatch, cancel and rerun workflows; set commit statuses |
| **Gists** | Gists and their files | Create, edit and delete gists |
| **Stars** | Starred repositories | Star and unstar |
| **Organizations and teams** | Your organizations, their members and teams | |
| **Email addresses** | Your email addresses, including private ones | |
| **Create and fork repositories** | | Create repositories and forks |

New connections read code, issues and pull requests, Actions and organizations.
Pull request files, commits and diffs, the pull requests of a commit, and activity
feeds also need Code read; merging a pull request or updating its branch needs
Write on both Code and Issues and pull requests. Code write includes workflow
files wherever GitHub grants the Workflows permission. Profiles, repository
lists and metadata, and repository and user search are always available.

GitHub's own permissions still apply: Houston only reaches repositories your
account, token or app installation can access.

Connect by signing in with GitHub, or with a personal access token. Archives, gist files,
release assets and workflow logs are saved as session files. Repository deletion, settings,
secrets, webhooks and administration are not available.
